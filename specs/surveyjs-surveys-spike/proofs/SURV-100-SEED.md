keys, operator state, snapshots and PDFs separate from other worktrees. Reserved
networks remain available across the real CLI resets and are removed by the
outer harness. A separate post-run Docker inventory verified that all project
containers, volumes and networks were absent.

Three focused safety tests also pass. They preserve existing local project names,
allow the narrowly defined numeric isolation suffix and reject arbitrary project
names, production mode, foreign endpoints, external data volumes and missing
required services. The isolated name never bypasses those target checks.

This is operator integration evidence, not a browser survey journey or independent
host-loss recovery proof. Backup, upgrade/rollback, the combined legacy regression
