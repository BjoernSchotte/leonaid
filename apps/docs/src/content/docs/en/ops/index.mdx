LeonAid runs locally as a Docker Compose system. A pilot installation uses the
same services with separate projects, domains, secrets, recovery targets, and
digest-pinned release images.

:::caution[Development and pilot status]
Synthetic repository tests do not approve a specific production environment.
DNS, TLS, mail, backup targets, operator details, and responsibilities require
separate acceptance for every installation.
:::
