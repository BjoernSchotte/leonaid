LeonAid separates its Python domain core, adapters, generated API contracts,
and several web interfaces. Changes are checked through the locked Docker
toolchain and the relevant executable contract.

## Start with your task

- **Tutorial:** [Make your first verified change](./tutorials/first-change/)
- **How-to guides:** [Update the API contract](./how-to/update-api-contract/),
  [debug](./how-to/debug/), and [add a Core migration](./how-to/add-migration/)
- **Reference:** [Generated API](./reference/api/) and
  [repository and commands](./reference/repository-and-commands/)
- **Explanation:** [Architecture and data ownership](./explanation/architecture-and-data-ownership/)

When sources disagree, start with implemented code and its tests. Specs, ADRs,
and runbooks explain decisions but do not replace current code or runtime
evidence.
