**Role:** every active account. Open **Wissen** (knowledge) in the back
office (`/admin/knowledge`) or in the app (`/app/knowledge`). The module needs
the task and material modules; if your installation switched it off, the
entry is missing.

## Create and edit a page

1. Select **Seite anlegen** (create page), enter **Seitentitel**, choose a
   campaign or **Eigenständig** (standalone) and confirm with **Seite
   anlegen**. A standalone page is first visible to you only. The new page
   opens for writing.
2. A page first shows for reading. **Bearbeiten** (edit, key `E`) opens the
   **Seiteninhalt** for writing. The toolbar formats text, for example **Fett**
   (bold), **Kursiv** (italic), lists, **Zentriert** (centered) or a font and
   size.
3. Select **Speichern** (`Ctrl`+`S`). The status shows **Gespeichert.** and the
   page returns to reading. **Abbrechen** (cancel) drops unsaved changes only
   after you confirm **Entwurf verwerfen?** (discard draft?).

Each save stores a new revision. If someone else saved the page in the
meantime, your draft stays and you choose: **Meine Fassung behalten** (keep my
version) saves your draft as a new revision, **Andere übernehmen** (take the
other) shows the other person's saved revision.

## Link tasks and file versions

- **Aufgabe aus dieser Seite** (task from this page, while reading) creates a
  task in a list you may edit and puts a reference into the page. The reference
  shows the current task status.
- While editing, **Einfügen** → **Material aus Ablage verknüpfen** picks a
  material; **Dateiversion einfügen** links exactly that file version, even
  after newer versions are uploaded.

A reference grants no access: people who cannot open the task or material see
it as unavailable.

## Share a page

Open the **Seitenfreigaben** with **Freigaben verwalten** (manage sharing), add
an existing active account by e-mail address and choose **Lesen** (read) or
**Bearbeiten** (edit). Removing **Seitenzugriff** withdraws access at once.
