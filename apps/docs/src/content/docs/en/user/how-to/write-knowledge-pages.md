**Role:** every active account. Open **Wissen** (knowledge) in the back
office (`/admin/knowledge`) or in the app (`/app/knowledge`). The module needs
the task and material modules; if your installation switched it off, the
entry is missing.

## Create and edit a page

1. Select **Neue Seite**, enter **Seitentitel**, choose a campaign or
   **Eigenständig** (standalone) and select **Seite anlegen**. A standalone page
   is first visible to you only.
2. Open the page and write in **Seiteninhalt**. The toolbar formats text, for
   example **Fett** (bold), **Kursiv** (italic), lists, **Zentriert**
   (centered) or a font and size.
3. Select **Speichern**. The status shows **Gespeichert.**

Each save stores a new revision. If someone else saved the page in the
meantime, your save is refused and your draft stays; load the current version
on purpose before you save again.

## Link tasks and file versions

Under **Einfügen**:

- **Aufgabe aus dieser Seite** creates a task in a list you may edit and puts a
  reference into the page. The reference shows the current task status.
- **Material verknüpfen** picks a material; **Dateiversion einfügen** links
  exactly that file version, even after newer versions are uploaded.

A reference grants no access: people who cannot open the task or material see
it as unavailable.

## Share a page

Under **Freigaben verwalten**, open **Seitenfreigaben**, add an existing active
account by e-mail address and choose **Lesen** (read) or **Bearbeiten** (edit).
Removing **Seitenzugriff** withdraws access at once.
